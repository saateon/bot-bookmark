# bot.py — تلگرام و هماهنگی

## اصل
هیچ منطق دامنه‌ای ندارد (نه صفحه می‌خواند، نه عنوان می‌سازد، نه JSON می‌نویسد) — فقط ماژول‌های همسایه را به‌ترتیب صدا می‌زند و خطاها را به پیام فارسی خوانا تبدیل می‌کند.

## حلقهٔ اصلی (`run`)
- ابتدا `config.validate()` — خطا → خروج با کد ۱ و فهرست فارسی مشکلات
- `getUpdates` long-poll با timeout=`TG_POLL_TIMEOUT=50`
- offset = بزرگ‌ترین update_id + ۱
- خطای حلقه → backoff نمایی ۳ → ۶۰ ثانیه؛ KeyboardInterrupt → خروج تمیز
- یک کلاینت httpx واحد برای تمام تماس‌های تلگرام

## پیام‌های ورودی (`handle_message`)
- chat_id ∉ `ALLOWED_CHATS` → **بی‌پاسخ** (بات شخصی است؛ حتی پیام «اجازه ندارید» هم نمی‌فرستد)
- متن خالی → نادیده
- شروع با `/` → `handle_command`
- بدون لینک → پیام کوتاه «لینکی پیدا نشد»
- چند لینک → اطلاع «n لینک دریافت شد» + پردازش ترتیبیِ مستقل

## دستورها
`/start` `/help` → راهنما | `/id` → آیدی عددی چت (برای گذاشتن در ALLOWED_CHATS) | `/ping` → خروجی `store.stats`
فرمان ناشناخته → پیام «فرمان ناشناخته»

## extract_urls — سه شکل لینک
`https?://…` | `www.…` | دامنهٔ لخت با پسوندهای رایج
(com net org ir io dev app ai me co info xyz shop site online tech store pro tv news blog cloud)
علائم نگارشی انتهایی حذف می‌شود؛ بدون اسکیم → `https://` اضافه؛ خروجی یکتا.

## process_link — هیچ خطایی ربات را نمی‌اندازد
- `reader.fetch` شکست خورد → عنوان = دامنهٔ لینک، ذخیره ادامه می‌یابد
- `add_link` → duplicate → «♻️ از قبل بود» | StoreError → «❌ ذخیره نشد»
- موفق → «✅ ذخیره شد [منبع]: عنوان + url» — منبع: هوش مصنوعی / توضیح صفحه / عنوان صفحه / دامنه

پیام‌ها به ۴۰۰۰ نویسه بریده می‌شوند (سقف تلگرام).
